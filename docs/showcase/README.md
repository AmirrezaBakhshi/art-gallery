# ArtGallery visual showcase

This showcase is captured from the running React and Django application by the Playwright browser workflow. It uses a fictional gallery account and original sample artwork generated during the test run. No real gallery-owner or visitor information is used.

## Screenshots

| Screen | What it demonstrates |

| [Home](screenshots/01-home.png) | Visitor entry point |
| [Sign up](screenshots/02-signup.png) | Gallery account creation |
| [Gallery setup](screenshots/03-gallery-setup.png) | Initial gallery setup |
| [Dashboard](screenshots/04-gallery-dashboard.png) | Gallery owner workspace |
| [Artwork editor](screenshots/05-artwork-editor.png) | Adding artwork and its image |
| [Collection](screenshots/06-gallery-library.png) | Owner's artwork library |

The images and recording show the real application interface with synthetic demo content. They are not mockups, and the repository does not currently provide a hosted live demo.
