# ArtGallery visual showcase

These screenshots and the short browser walkthrough are captured from the running application by Playwright. The demonstration uses a fictional gallery account and original sample artwork generated during the test run; it does not use real gallery-owner or visitor data.

| [Artwork editor](screenshots/05-artwork-editor.png) | Adding artwork and its description |
